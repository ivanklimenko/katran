# `apps/pi`

Прикладное приложение монорепо `katran`: реестры платёжных инструкций «Валютные документы» (`#/fx-docs`) и «Рублёвые документы» (`#/rub-docs`) на FSD, с переносимым швом данных (`requestFx`) и фейковым сервером на контракте `vtb-filters`. Собран на компонентах `@katran/ui` и моделях `@katran/effector` — кит, а не сам `apps/pi`, переиспользуется как библиотека.

Для команды, переносящей эти реестры во внутреннее приложение — `docs/guides/pi-usage.md`. Для бекенда — контракт эндпоинтов и состав строки — `docs/reference/pi-api.md`.

## Запуск

```sh
pnpm --filter pi dev
```

Dev-сервер — порт **5185**. Данные — фейковый сервер в браузере (`src/app/fake/`), 87 записей на каждый реестр, ходить в сеть не нужно.

## Тесты

```sh
pnpm --filter pi test   # vitest — мапперы, порты, createRegistry, компоненты, доступность (axe)
pnpm --filter pi e2e    # playwright — геометрия реестров и деталки на production-сборке
```

`e2e` собирает приложение и поднимает превью на порту **5186** (`playwright.config.ts`, `webServer`) — отдельно от dev-порта 5185, чтобы не мешать друг другу при параллельном запуске.

## Регуляторы фейкового сервера

Только для разработки без бека (`src/app/fake/params.ts`) — у настоящего транспорта их нет:

| Параметр адреса | Действие |
|---|---|
| `?slow=N` | фиксированная задержка ответа `N` мс (по умолчанию — случайная 0,25–0,65 с) |
| `?fail=search` | `search` текущего грида отвечает `500` |
| `?fail=facets` | `facets` текущего грида отвечает `500` |
| `?fail=meta` | `filter-meta` текущего грида отвечает `500` |
| `?fail=suggest` | подсказки при вводе (`POST …/suggest`) отвечают `500` — список подсказок не появляется, фильтр работает |
| `?fail=detail` | деталь документа (`GET …/documents/{id}`) отвечает `500` — ошибка внутри drawer'а с «Повторить», реестр работает |
| `?fail=tab` | любая вкладка деталки (`GET …/documents/{id}/tabs/{tab}`) отвечает `500` — ошибка внутри вкладки с «Повторить», шапка и другие вкладки работают |
| `?fail=tab:<id>` | `500` только на вкладке `<id>` (`?fail=tab:audit`) |
| `?fail=edit` | сохранение правки (`POST …/documents/{id}/edits`) отвечает `500` — ошибка строкой под редактором, «Сохранить» — повтор (срез 2c) |
| `?fail=accounts` | справочник счетов (`GET …/documents/{id}/accounts`) отвечает `500` — «Не удалось загрузить счета» с «Повторить» в правке счёта |
| `?fail=decide` | утверждение и отклонение чужой правки (`POST …/documents/{id}/edits/{target}/confirm`, `…/reject`) отвечают `500` — текст ошибки в `Prompt` решения, кнопка доступна для повтора (срез 2d) |
| `?fail=message` | скачивание сообщения (`GET …/documents/{id}/message`) отвечает `500` — объявление с текстом ошибки |
| `?fail=print` | печатная форма (`GET …/documents/{id}/print/{form}`) отвечает `500` — вкладка «Формируется…» закрывается, объявление с текстом ошибки |
| `?conflict=edit` | любая правка отвечает `409` — «Документ изменили — откройте заново», деталь перезапрашивается |

Регуляторы читаются из `location.search`, поэтому ставятся **до** `#`: `http://localhost:5185/?fail=search#/fx-docs` — реестр валютных документов показывает состояние ошибки с кнопкой «Повторить».

Отдельно, вне регуляторов сервера — `?hostile` подключает `public/hostile.css` (глобальные стили «враждебного хоста») для проверки изоляции кита от окружения; используется в `e2e/isolation.spec.ts`.

## Деталка

Деталка «Платёжная инструкция» на просмотр (срезы 2a и 2b): кнопка открытия записи — drawer A, двойной клик или Shift — drawer B рядом для сравнения, Esc закрывает верхний; все вкладки валюты и рубля, нелокальные грузятся лениво (`GET …/documents/{id}/tabs/{tab}`), ID связанного документа открывает его в B; как подключить к своему реестру — `docs/guides/pi-usage.md` §13, как добавить вкладку — §13.7.

Правка валютной деталки (срез 2c): SWIFT-поля «Общих данных» по профилю, 20 исх, счета Дт/Кт из справочника, дата валютирования с подтверждением; маркер «изменено», аудит, ↺; уход с несохранённой правкой спрашивает «Отменить правку?». Рубль и заблокированные документы — только просмотр. Эндпоинты `POST …/documents/{id}/edits` и `GET …/documents/{id}/accounts?side=`; как подключить — `docs/guides/pi-usage.md` §14 (в другом реестре — §14.6).

Действия лейна и «вторая рука» (срез 2d): «Обновить» и F5, «Скопировать ссылку» (`#/<грид>?doc=<id>`, по ссылке открывается деталь), «Скачать» сообщение SWIFT/ED, «Печать» формы PDF во вкладке; у чужой правки — «Утвердить» и «Отклонить» (с причиной) в `fx-docs`. «Редактировать» из лейна убран, «Создать служебный документ» и «Аннулировать» — заглушки до среза 2e. Эндпоинты `POST …/edits/{target}/confirm|reject`, `GET …/message`, `GET …/print/{form}`; как подключить — `docs/guides/pi-usage.md` §15.
