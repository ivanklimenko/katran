# Деталка документа: чем katran (срез 2a) отличается от эталона pi-constructor

Список расхождений деталки «Платёжная инструкция», перенесённой срезом 2a в кит и `apps/pi` (`docs/superpowers/specs/2026-09-29-katran-detail-view-design.md`), с замороженным эталоном стенда. Нужен для плана работ: пункты классов A, B и D владелец решает и отправляет в план, пункты класса C фиксируются, чтобы их не «чинили» (STATE §10, спека §2, принцип 6). Сверка составлена до кода (Task 1 плана 2a) и переведена в факт по готовому коду (Task 12): колонка «katran (срез 2a)» показывает, что сделано и где.
