## 2. Типографика и вертикаль записи

**Три кегля (T1).** Основное значение — `fs-1` 12.5 / `lh-1` 17. Вторые строки ячеек и сквозные строки — `fs-2` 11 / `lh-2` 14, тон `muted` (причина и назначение — `ink2`). Подписи — `fs-3` 10.5 прописными (наименования банков и сторон в 50–59).

`CopyValue`: проп `size?: 's' | undefined` (второй кегль: `fs-2` / `lh-2`) и тон `'muted'` в `tone`. По умолчанию — как сейчас.

**Вертикаль записи (Г2).** Токены: `grid-pad` 6 → 8, новый `grid-gap` 3 (промежуток между строкой колонок и первой сквозной строкой). Запись: 8 + 2 × 17 + 3 + 14 + 8 + 1 = 68. Коридор e2e — прежний (64–72), цель — 68.

**Цвет значений (T2, решение В4).** В гриде значения — `ink`, синий `val` — только линк-кнопки (uuid, refIn, refOut). Раскладка демо задаёт `tone="ink"`; умолчание `CopyValue` (`val`) не меняется — оно для деталки (основная спека 4.2 уточняется).

**Шапка (T3, T6, решение В3).** Заголовок и подзаголовок — прописными, `letter-spacing` 0.5px. Наведение на сортируемый заголовок подсвечивает всю ячейку шапки (`hover`), а не только кнопку внутри паддинга.

**Мелкие ячейки.** R15 — «S:» / «R:» sans `fs-2` `faint` шириной `sp-4` (14 → ближайший токен), BIC — mono `fs-1` `ink`. R16 — тип: `Tag tone="mt"` (mono 600 `fs-2` `ink2`, рамка `line`, фон `paper`). R17 — номер в ID — 600 `ink`.

## 3. Колонки и ячейки

**`SwiftField`** (новый, `@katran/ui/value`) — ячейка SWIFT-поля:

```ts
export type SwiftFieldProps = {
  /** Буква опции (A, F, K…); нет — не показывается. */
  opt?: string | undefined
  /** Главное значение: счёт или BIC; пусто — «—». */
  main: string
  /** Подпись ниже: наименование банка или стороны, прописными. */
  caption?: string | undefined
  /** Обрезка главного значения, px при плотности 1; полное — в тултипе. */
  maxWidth?: number | undefined
  tabIndex?: number | undefined
}
```

Буква опции — mono 700 `fs-1` тоном `opt`; главное значение — `CopyValue` mono `fs-1` `ink`; подпись — `CopyValue` `fs-3` прописными `muted` (копируется). Клавиатура и копирование — как у `CopyValue`.

**Колонки демо:**

- **50 / 59 (R12)** — `SwiftField` со счётом целиком (обрезка 130) и наименованием. Подзаголовок 50 — «приказодатель · 70»; ключи 50 — «Наименование», «Счёт», «Назначение (70)»; у 59 подзаголовка нет.
- **52 / 57 / 58 (R13, R1)** — `SwiftField` с опцией, BIC и наименованием банка. 58 — между 57 и 59; заполнено у MT202, иначе «—». Сегмент назначения 50–59 покрывает 58.
- **«Маршрут» (R3, R4)** — `fullHeight`, три строки: `Tag` типа (LORO / NOSTRO / INTERNAL), BIC получателя mono `ink2`, счёт 8…4. Ключи «Тип маршрута» (`routeType`), «Receiver» (`routeRecv`).
- **«S / R out» (R2)** — `fullHeight`, как «S / R in»; ключи `outSender`, `outReceiver`.
- **«Дата / Время» (R10)** — дата `ink` и время `muted` (формат «22.09.2026 07:33:22», решение В5), ниже «Дт …», «Кт …» `fs-2` `muted`; Кт — тоном `warn`, если отличается от Дт. Часть «Валютирование» (режим «раздельно») — те же строки Дт / Кт.
- **«Направление» (R11)** — иконка группы (↓ IN, ↗ OUT, ⇄ TRANSIT, ◦ OTHER) и код mono 600 `fs-3` `ink`; ниже название `fs-2` `muted` с обрезкой 105. Иконки — в демо (в `apps/pi` переедут в сущность документа).
- **«Провайдеры» (R14)** — два тега столбиком: отправитель `Tag tone="warn"`, получатель `Tag tone="ok"`.
- **Причина статуса (R8)** — перед текстом `StatusDot size="s"` цвета статуса; текст `fs-2` `ink2`, обрезка с «…».
- **Назначение 70 (R9)** — метка `FieldTag tag="70" title="70 · Детали платежа"`; текст `fs-2` `ink2` прописными, разрядка 0.02em.

**`Tag`** — тоны `'mt' | 'warn' | 'ok'` в дополнение к `neutral`, `opt`; контраст текста тегов проверяется тестом токенов.

**Счёт 8…4 (F3).** `shortAccount` по умолчанию: первые 8 знаков (5 + код валюты жирным) … 4 последних. Смена вида по умолчанию для всех потребителей — CHANGELOG «Изменено». Параметр длины хвоста (рубль 8…3) — задача 3 плана `apps/pi`.

**Ширины по умолчанию (Г3,** полная ширина ячейки): статус 60, ID 106, «Дата / Время» 121, «Тип» 71, «Направление» 127, 32 — 96, 50 — 157, 52 / 57 / 58 — 137, 59 — 157, «Маршрут» 110, «S / R in» и «S / R out» — 113, «Провайдеры» 122. Служебная колонка — 100 (R7, класс C).

**Данные демо** — вымышленные, по генератору эталона: `f58` (MT202), опции и наименования сторон и банков 50–59, `outSender` / `outReceiver`, `routeType` / `routeRecv` / `routeAcc`. Словари эталона обезличены; реальных BIC нет. Новые вызовы ГПСЧ — в конце объекта записи, чтобы прежние значения не сдвигались.

## 4. Статусная точка, лейн, строка фильтров, подвал, скелетон

**Статусная точка (T5).** В записи — 16 px (`dot-m` 14 → 16), глиф 700 `fs-3`; `StatusDot` умеет `letter`. Словарь глифов — у приложения, один для записи и лейна:

| Статусы | Глиф |
|---|---|
| Обработан, Экспортирован | ✓ |
| Ошибка, INVALID | ✕ |
| Отказ | ⊘ |
| Отложенный | ! |
| В работе, К экспорту, В обработке | · |

Тултип «Обработан · DONE» — как есть.

**Лейн (L1).** Полоса на всю ширину, высота 36 с линией `line` снизу; кнопка 32; активная — подчёркивание 2 px `val` (без рамки); точка 14 с глифом (`LaneItem.glyph?: string | undefined`); счётчик — пилюля (`Counter`). Семантика прежняя: `role="group"` с кнопками `aria-pressed` (это фильтр, не `tablist`). `StatusLane` использует свою кнопку вместо `Button ghost`.

**Строка фильтров (P3).** Полоса `sunk` высотой 45 на всю ширину. Кнопка «Фильтры» — основная (`val`) с иконкой воронки и бейджем числа условий. Чип условия — фон `val-soft`: поле `ink2` · оператор mono `fs-3` `muted` · значение 600, затем ✕. «Сбросить» — чип. Оператор — словами (P5, класс C). Новая функция `conditionParts(c: Condition, meta: FilterMeta | null): { field: string; op: string; value: string }`; `describeCondition` остаётся (тултип, доступное имя чипа). Тело панели и поведение не меняются.

**Подвал (W4).** Полоса `sunk` 37: слева «1–20 из 87»; в центре компактные кнопки ‹ 1 2 … 5 › (22 px; текущая — фон `val`, текст `paper`; многоточие: первая, текущая ± 1, последняя); справа «На странице» — `Select` с вариантами `pageSizes`. «Назад» / «Вперёд» — стрелки ‹ › с доступными именами «Назад» и «Вперёд». Демо — `pageSizes` 10 / 20 / 50 / 100. `BulkBar` остаётся над пагинацией; «выбрано N» в подвале нет (B9, класс C).

**Скелетон (Z1).** В служебной колонке — порядковые номера строк страницы, как в записи; плашка колонки с `align: 'right'` прижата вправо.
