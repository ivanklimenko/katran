Кит не знает про статусы, задачи и комплаенс — только таблица, бейдж, список, код и форматтеры. Всё проходит `check:target` (Chromium 88: без `.at`, `Object.hasOwn`, `:has`, `inert`; `DOMParser` есть), React 17–19.

## 3. `apps/pi`

### 3.1. Контракт и порт

- **Эндпоинт — предложение** в контракт `vtb-filters`, как `/facets` и деталь: `GET /grids/{gridId}/documents/{id}/tabs/{tab}` — данные одной вкладки. `tab` — id из `FX_TABS` / `RUB_TABS` без локальных: `statuses`, `compliance`, `linked`, `tasks`, `notif`, `source` (валюта) / `ed244` (рубль), `stream`, `mpu`, `audit`. Неизвестный `id` документа или вкладка не из набора реестра → 404. Состав каждой вкладки — в `docs/reference/pi-api.md` с пометкой «предложение».
- **Локальные вкладки** — `main` и `extra`: данные приходят в детали (как `TAB_LOCAL` эталона). Если `FxDocDetail` не хватает референсов (docReference Вх/Исх, связанный reference, UETR) или дат валютирования (`vd`), деталь расширяется. При исполнении (Task 10) расширять не понадобилось: «Доп. поля» собираются из полей строки и детали 2a (поля `20`/`21` в `fields`, `refOut`, `uetr`, `valueDates`).
- **`tabsOff`** по-прежнему приходит в детали — бек знает, у каких вкладок нет данных, до их запроса.
- **Порт.** `createGridPorts({ gridId, parseRow, parseDetail, parseTab })` добавляет `tabFx: Effect<{ id: string; tab: string }, unknown, ApiError>`; `parseTab: Record<tabId, Parser>` — парсеры на гардах, вкладка без парсера и битая форма → `contractError`, как у поиска и детали.

### 3.2. Сущность `entities/doc-trail`

История обработки документа — общая для обоих реестров, поэтому отдельная сущность, а не копия в `fx-doc` и `rub-doc`.

- `model` — типы вкладок: `StatusEvent[]`, `Compliance`, `LinkedDoc[]`, `Task[]`, `Notification[]`, `StreamEvent[]`, `MpuMessage[]`, `AuditSections` (секция → объект), `SourceTexts` (ключ → строка); `toneOf` — тон бейджа по коду решения и статуса (ALLOW → ok, REVIEW → wait, прочее → bad; OK / SENT → ok; TIMEOUT → bad; прочее → wait) — одна таблица на все вкладки. При исполнении (Task 7): задачи и нотификации — `DocTask[]`, `DocNotification[]` (имена без конфликта с глобальным `Notification`); `toneOf` — один список «зелёных» (`ALLOW`, `OK`, `SENT`, `DONE`, `EXPORTED`, `PASSED`) и «красных» (`TIMEOUT`, `DENY`, `BLOCK`, `ERROR`, `FAILED`, `REJECTED`, `INVALID`) кодов, неизвестный код — `wait`; состав ответа каждой вкладки — `docs/reference/pi-api.md` §8.
- `api` — мапперы на гардах (имена полей бека — только здесь), примеры для `pi-api.md` и контрактных тестов, `parseTab`-таблица для портов обоих реестров.
- `ui` — виды вкладок на блоках кита: `StatusesTab`, `ComplianceTab`, `LinkedTab`, `TasksTab`, `NotificationsTab`, `SourceTab`, `StreamTab`, `MpuTab`, `AuditTab`. `SourceTab` один на `source` и `ed244`: язык `CodeView` — XML, если строка начинается с `<`, иначе SWIFT (как на эталоне). Пустое состояние — текст эталона («Статусов нет», «Комплаенс-проверок нет», «Связанных документов нет», «Задач нет», «Нотификаций нет», «Исходного текста нет», «Событий стриминга нет», «Сообщений MPU нет», «Аудит пуст»).
- «Доп. поля» — `ExtraTab` в `entities/fx-doc` по конфигу `XTAB` эталона (`index.html:650–667`), рядом со SWIFT-профилями: SWIFT-поля с номером `FieldTag`, референсы с «N симв.», даты валютирования с выделением отличающихся от первой.

### 3.3. Виджет `widgets/doc-detail`

- **`createDetail({ detailFx, tabFx?, localTabs?, lifecycle })`.** Запрос вкладки уходит, когда нелокальная вкладка становится активной в слоте (`setTab` или открытие с запомненной вкладкой). Кэш по ключу `id:tab` — на время открытого экрана; повторное открытие и переключение A↔B не перезапрашивают. Счётчик визитов защищает от гонки при быстром переключении. У вкладки своё состояние `loading | ready | error`, событие `retryTab({ slot, tab })`; ошибка вкладки не трогает шапку, лейн и другие вкладки. `pageClosed` очищает и кэш вкладок.
- **Состояние раскрытия** — в модели, картой по `id` документа, до `pageClosed`: `TabPanel` размонтирует неактивную вкладку, а раскрытое должно переживать переключение (закрывает пункт техдолга §7 про «Общие»). Умолчания — как `mkui` эталона: раскрыты первая связанная запись, `commonSection` аудита, все исходники, первое сообщение MPU; задачи свёрнуты.
- **`DocDetail`** получает `tabViews: Record<tabId, (data, ctx) => ReactNode>`; `ctx` — `onOpenDocument(id)`, `announce`, раскрытие вкладки (`expanded`, `setExpanded`). Скелетон вкладки — минимум 400 мс через `useLoadingGate`, как у грида; ошибка — `ErrorState` с текстом `ApiError` и «Повторить». `doc-detail` по-прежнему не импортирует `entities`.
- **Уточнено при исполнении (план 2b, Task 11).** Вкладка грузится независимо от детали (эндпоинт самостоятелен; вкладку, выбранную до загрузки и оказавшуюся в `tabsOff`, `DocDetail` переводит на «Общие» — техдолг M-f закрыт); триггер — смена записи слота (`setTab`, сдвиг B в A), открытие всегда на «Общих»; `retryTab(slot)` вместо `retryTab({ slot, tab })` — повторяется активная вкладка слота; `tabViews` — объекты `TabView` (`local`/`remote`, `remoteTab`) вместо функций, `ctx` — `docId`, `openDocument`, `announce`, `expanded`, `setExpanded`; повторный выбор вкладки с ошибкой — новый запрос; раскрытие — `$expanded` по ключу `id:tab`, у «Общих» — управляемый `ConfigForm` (техдолг M-g закрыт).

### 3.4. Страницы

`pages/fx-docs`, `pages/rub-docs` собирают `tabViews` (виды `doc-trail`, у валюты — плюс `ExtraTab`) и передают `tabFx` из портов сущности. «Связанный» → `detail.open` со слотом B; документ, уже открытый в любом слоте, повторно не открывается — фокус в его drawer (правило 2a). При исполнении: виды собирает страница (`pages/*/ui/detailDomain.ts`), `localTabs` — константы моделей страниц (`FX_LOCAL_TABS = ['main', 'extra']`, `RUB_LOCAL_TABS = ['main']`).

### 3.5. Фейк

- `GET …/documents/{id}/tabs/{tab}` строит данные детерминированно по `id` документа; словари — со стенда, обезличены, данные вымышленные.
- Рубль — свои данные: суммы в RUB, рублёвые счета, сценарии `SC_NCB_*` в статусах, события стриминга рубля, ED244 вместо SWIFT; «Связанные» и MPU бывают непустыми.
- «Связанные» ссылаются на существующие документы того же реестра (`docId` открывается в B).
- `tabsOff` детали согласован с данными: вкладка пуста ⇔ она в `tabsOff`.
- `?fail=tab` → 500 на любой вкладке, `?fail=tab:<id>` — только на одной.

## 4. Поведение

- **Раскрываемые строки** («Связанные», «Задачи») — мышью и клавиатурой (Enter/Space), `aria-expanded`; ссылки и кнопки внутри строки её не раскрывают.
- **Аккордеоны** — `Disclosure`; пустой исходник не раскрывается, в заголовке — «нет».
- **Заглушки** — «Переотправить», «Перейти в блок «Ручные отклонения»», «История», «Исходное сообщение»: кнопки с `announce` «Действие будет в 2d», как у лейна 2a.
- **ID связанного документа** — ссылка-кнопка «Открыть … в соседней панели» (открывает в B) и `CopyValue` рядом.
- **Длинный текст** (причина статуса, текст задачи, назначение) — обрезка многоточием, полный текст в тултипе и доступном имени.
- **Esc** — как в 2a (R13); внутри `CodeView` и раскрытых строк не перехватывается.
- **Геометрия** — как в 2a (В-Д6 «а»).

## 5. Проверки

- **Кит.** `MiniTable`: колонки, `numbered`, пустое, раскрытие мышью и клавиатурой, клик по ссылке внутри, контролируемый режим, axe. `CodeView`: JSON; SWIFT (блоки, теги, UETR); XML — глубина, порог 92, битый XML → сырой текст; отсутствие `innerHTML`; номера строк вне текста. `StatusBadge`, `KeyValueList` (пусто → «не заполнено»), `formatTimestamp` и `formatDuration` на границах. Д28 — вычисленные стили метки в e2e.
- **`apps/pi`.** Мапперы каждой вкладки на примерах из `pi-api.md`, включая битую форму; цепочка «порт → `requestFx` → фейк» для `tabFx`: 200, 404, 500 по `?fail=tab` и `?fail=tab:<id>`; `createDetail` — ленивая загрузка, кэш `id:tab`, повтор вкладки, гонка, `pageClosed`, раскрытие переживает переключение; каждый вид под axe на данных валюты и рубля; фейк — `tabsOff` совпадает с пустотой данных.
- **e2e** на production-сборке `apps/pi` (передний план): высоты строки таблицы 24, шапки 22, строки «ключ–значение» 24, раскрываемой строки 26 — против замера эталона ± 2; «Связанный» открывает B; ошибка вкладки и «Повторить»; переключение вкладок не перезапрашивает; `?hostile`; скриншоты сверки рядом с эталоном. При исполнении: e2e без сети — фейк внутри страницы, отсутствие перезапроса проверяется взведённым `?fail=tab`.
- **Совместимость.** `check:target` (Chromium 88); React 17.

- Эндпоинт вкладок — предложение владельцу контракта `vtb-filters`; до согласования форма ответа — черновик.
- Ссылка связанного документа из другого реестра (например, рублёвый документ, связанный с валютным) — вне среза; понадобится межреестровая навигация.
